# Auréa Beauty Studio — Projeto de portfólio

Site conceitual fictício desenvolvido com React, TypeScript, Vite e Tailwind CSS.

## Executar localmente
1. Instale Node.js LTS.
2. Abra um terminal nesta pasta.
3. Execute `npm install`.
4. Execute `npm run dev`.
5. Abra o endereço local indicado pelo Vite.

## Validar compilação
Execute `npm run build`.

## Observações
Auréa Beauty Studio é uma marca fictícia. Endereço, preços, horários e experiência são demonstrativos. Não há CNPJ atribuído, reservas reais ou transações. Os botões de agendamento apenas exibem um aviso de demonstração. As fotografias de ambiente são carregadas de URLs do Unsplash, portanto exigem conexão com a internet.
